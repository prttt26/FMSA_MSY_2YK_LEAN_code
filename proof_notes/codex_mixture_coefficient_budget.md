# Effective coefficient certificate for the actual mixture Fourier cutoff

`MixtureCoefficientBudget.lean` replaces the nonconstructive amplitude-ball bound in the high-frequency cutoff with a finite expression built from four interval caps on the actual Blum–Høye coefficient families: `A_j`, `q′_ij`, `W_uij`, and `C_uij`. These are the values produced by `amplitudeA`, `amplitudeQp`, `W`, and `C` from the original `(D,G)` amplitudes. The caps must bound the absolute value of every coefficient at every state being certified.

`originCap` bounds each entry of the actual zero-distance causal kernel using its recentered `t = 0` identity. `lowerCap` and `upperCap` bound the two parts of the proved `1/|s|` remainder estimate. `explicitBudget` is the finite sum of these three cap contributions over all species pairs. Theorems `origin_kernel_le_originCap`, `decayBudget_le_coefficientBudget`, and `decayBudget_le_explicitBudget` prove that the actual `decayBudget` is at most this computed expression. These proofs use only finite sums, absolute-value inequalities, and the actual BH definitions; they assume neither a root equation nor canonicity.

For a path set `S`, `path_axis_zero_free_of_coefficient_caps` takes uniform four-family caps and determinant nonvanishing for **every** `t ∈ S` and `|k| ≤ rateCutoff(z) + explicitBudget + 1`. It concludes determinant nonvanishing for all real `k`. The endpoint theorem `MixtureEndpointNoEscape.exists_hs_maximal_branch_at_explicit_coefficient_first_axis_loss` specializes this to a closed continuous same-HS-seed actual root path on `[0,b]`, an endpoint physical Fourier zero, and the finite-window certificate on `[0,b)`. It constructs the HS maximal branch, proves its bound is `b`, and identifies the unique selected physical endpoint root.

The same certificate now yields **amplitude noescape directly**, with weaker path assumptions. `MixtureEndpointNoEscape.hs_axis_zero_free_prefix_uniform_amplitude_bound` proves that a continuous same-HS-seed actual MSA root path and physical Fourier zero-freeness on all real frequencies have one uniform original `(D,G)` norm bound; the full half-plane factor condition is derived from the proved zero-free path theorem. `hs_coefficient_certificate_uniform_amplitude_bound` replaces all-frequency zero-freeness by the four coefficient caps and determinant nonvanishing on the explicit finite frequency window. These two results require only continuity on `[0,b)` and make no claim about `p(b)`.

The cap inequalities and bounded coupling-frequency determinant certificate remain continuum obligations for a concrete mixture. A finite floating-point sample is insufficient. Rational interval arithmetic may discharge them without any nonconstructive compactness cutoff. The theorem makes no statement about Taylor convergence or radius equality.
