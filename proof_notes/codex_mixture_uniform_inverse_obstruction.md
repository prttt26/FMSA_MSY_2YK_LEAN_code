# Inverse bounds at a mixture axis-loss endpoint

`MixtureUniformInverseObstruction.lean` records the precise endpoint limitation of finite Fourier sample certificates. It first proves that the actual full-line Baxter Fourier Q entry is smooth in the original `(D,G)` amplitudes at **every fixed real wave number, including zero**. This uses the frozen foundation's `fourierQ_eq_basis`: finitely many fixed integrable basis transforms multiply the actual smooth BH coefficient functions. Consequently the actual density-weighted Fourier factor is continuous in the amplitudes at every fixed real frequency.

The generic finite-matrix theorem `no_uniform_inverse_bound_at_singular_endpoint` says: if a matrix path is left continuous at `b>0`, its determinant vanishes at `b`, and it is invertible for every `t∈[0,b)`, then there is no real `R` bounding the entry-norm sum of every inverse on `[0,b)`. The proof selects a sequence approaching `b`, extracts a convergent subsequence of hypothetical bounded inverses in the finite matrix space, and passes the identity `F(t)F(t)⁻¹=1` to the limit. That would make the singular endpoint matrix invertible. `no_uniform_actual_inverse_at_axis_loss` applies this to the actual mixture Fourier factor using only left continuity of the original amplitude path on `[0,b]`.

This does not contradict the analytic mixture amplitude properness theorem: the original amplitudes can remain bounded while the Fourier factor inverse diverges at the first axis zero. It also distinguishes the two certificate uses. A finite uniform inverse budget is natural on a compact prefix strictly before loss; zero-freeness alone does not provide one uniform inverse budget all the way to a singular endpoint. The theorem makes no claim about the Taylor radius or the location of other complex singularities.

The stronger `no_uniform_mesh_certificate_at_axis_loss` proves that the specific **equally spaced frequency mesh** cannot retain its uniform sample inverse budget over the whole open prefix when its window contains the endpoint zero and its uniform first-moment and strict step conditions hold. Lean first generalizes the finite-matrix inverse perturbation bound from half-size changes to every product budget `q<1`, obtaining `N C/(1-q)`. The mesh then propagates its fixed sample bound `R` to a single uniform inverse bound at the loss wave number. This contradicts the endpoint theorem above. The statement takes the actual full-line first-moment inequality, the same moment budget and mesh arithmetic as the earlier grid certificate, and the actual Fourier factor; it does not treat sampled floats as a proof.

The value of a maximal canonical branch at its excluded endpoint is arbitrary, so `no_uniform_inverse_bound_at_singular_left_limit` uses the genuine left limit instead. `maximal_finite_mixture_endpoint_amplitude_bounded_inverse_unbounded` combines the analytic mixture properness theorem, the unique selected physical endpoint and its first real-axis zero: original `(D,G)` amplitudes are uniformly bounded on the finite prefix, while the inverse at one loss frequency has no uniform entry-norm bound there. `exists_hs_branch_with_bounded_amplitudes_and_unbounded_endpoint_inverse` constructs this branch directly from positive finite rates and diameters, nonnegative species densities with `etaMix<1`, and symmetric coupling. Finiteness of the maximal endpoint remains conditional; no Taylor-radius statement is made.

The exact-guard checker verifies thirteen theorems using only `propext`, `Classical.choice`, and `Quot.sound`; foundation 1.0.17 is unchanged. Per the user's memory constraint, run Lean with `scripts/lean_memory_limited.py`, which enforces a 30 GiB RSS ceiling and Lean's own memory limit, and run the full checker with one concurrent compiler:

```bash
LEAN_BIN="$PWD/scripts/lean_memory_limited.py" PYTHONDONTWRITEBYTECODE=1 python3 scripts/check_project.py -j 1
```

The wrapper exits unsuccessfully if the ceiling is crossed. It was also tested with an intentionally low 64 MiB ceiling, where it returned exit 137 rather than reporting a proof pass. No tmux session is needed for validation.
